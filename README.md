This Project is very barebones and mainly serves to demonstrate my understanding of Object Oriented Programming and not representative of my current coding skills. I created this project in my second semester of University with little to no prior experience coding. Currently, it only asks for your name and outputs a demonstration of what a battle would look like. In the future, I may update this project to function fully with user inputs and AI opponents.

Running the project:
1. Open "CardGameProject.py" in your favorite IDE
2. Run it in the terminal
3. Input your name when you are prompted and press enter
